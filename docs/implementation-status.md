## 能力边界

执行器支持 Go 模块、JavaScript/TypeScript/Python 脚本和网页，禁动态安装、任意宿主 Shell、外部 API/数据库及生成应用单独发布。网页内存状态随预览刷新重置，平台状态持久；匿名 Cookie 清除后无账户找回。

单节点、全局单任务并发，作业 CPU 0.5/内存 768 MiB/192 进程，禁网络/宿主挂载。外层 gVisor 隔离；Chromium 在该隔离内使用 no-sandbox，不能宣称启用了其内层沙箱。文件/调用有上限，历史数据库需运维监测容量。不承诺高并发、高可用、模型内部状态恢复；需求完整性仍需人工验收。
