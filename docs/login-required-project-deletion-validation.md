# 登录、共享项目与历史删除验收记录

日期：2026-11-13（北京时间）。状态：需求与技术方案已确认，代码和本地隔离验证已完成，等待人工验收；本轮未部署生产、未删除任何已有用户项目、未调用真实模型。

## 实现结果

- 未登录仅可初始化登录、注册/登录，以及查看明确公开的示例说明和分享。项目列表、文件、导出、预览、事件、应用数据、复制和 AI 操作均要求有效账号；保留来源检查、CSRF 校验、会话撤销和登录限流。
- 所有登录账号共享全部项目，包括历史游客项目。任何账号都能操作其他账号的项目。文件继续按原工作区保存；新 AI 运行的额度及账号并发归发起者，已有运行和额度不重写。
- 登录页参考 atoms.dev 的左右分栏，提供现有用户名/密码登录和注册。统一处理 JSON 请求及下载的登录失效，关闭旧工作台、事件和预览；按账号恢复本标签页的未发送草稿，不自动发送 AI 指令或复制项目。
- 历史项目行增加删除按钮和确认框。删除当前项目回到新建页；删除其他项目保持当前选择。运行或收尾中返回冲突。数据库事务清理整个项目及关联数据，保护其他项目和历史仍引用的文件，保留账号、额度和复制去重回执。
- 删除演示副本会更新原项目的可用状态并通知已打开页面；旧复制请求返回 `410 copy_deleted`。回滚标记要求账号登录、全局共享、发起者计费及删除语义，不能只依据表结构兼容恢复旧版。
