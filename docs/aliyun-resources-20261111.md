后续需用实现后的单任务测试记录 CPU、峰值内存、磁盘与耗时；当前 CPU 为瞬时采样，不是容量测试。网关容器采样期间 Kafka 出现过明显 CPU 峰值，需保留既有服务余量。生产公开运行不可信产物前还需验证隔离能力，不能仅凭 Docker 存在即宣称就绪。
