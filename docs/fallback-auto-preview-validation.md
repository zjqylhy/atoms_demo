# 自动进入演示预览验证记录

日期：2026-11-14（北京时间）。需求、技术方案均经用户确认；用户已认可结果并批准发布。[发布记录](shared-order-fallback-deployment-20261114.md)另列线上验证与范围。

## 实现结果

- 当前页面提交或跟随的运行失败后，读取既有演示副本，验证交付预览并等待应用数据连接成功，再切换地址和显示提示。
- 提示“大模型服务不可用，已切换至演示应用兜底。”，同时注明预置性质，提供原因和返回原任务入口。
- 同一次运行只自动尝试一次；返回、刷新或其他账号启动任务不会重复抢走页面。主动导航和账号变化取消迟到跳转。
- 副本、预览授权或载入失败时保留原任务；20 秒内没有完成连接则提示超时，可手动重试。
- 来源地址经过服务端关系核对；原任务已删除时仍可使用存活的演示，隐藏返回按钮。
- 不改动后台兜底判定、模型重试或业务数据。保留本轮开始前已有的预览版本刷新修复，并单独提交。
